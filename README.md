Objetivo
El objetivo del proyecto es copiar el diseño CCS y la estructura HTML de una pagina web dada, intentando buscar soluciones a los problemas de diseño y estilos.

Tecnologias:
Teconologias utilizadas: CCS y HTML.

Estructura:
Organizacion: toda la estructura esta contenida en main-flex con margin 0 y padding 0 y flex-box.
Ese main-flex contiene: un header donde se encuentran dos iconos y el titulo, un titulo principal con la etiqueta title-card, un text area donde el usuario ingresa el texto a analizar junto con los checkbox con diseños por default anulados, contiene 3 cartas con la cantidad de letras, palabras y oraciones, barras de porcentaje que reflejan las cantidad de letras que hay y su porcentaje, y por ultimo un footer de "see more" sin interaccion.

Dificultades:
Las mayores dificultades que encontre fueron  degenerar un estilo a travez de CCS sin usar background-image principalmente para las clase "card...", se me complico encontrar patrones que sean similares al diseño buscado. Por ultimo use Copilot para la imagen del titulo y la imagen del cambiar tema porque se iba alargar mas, y entendi que es mucho mas simple usar lo ultimo.
Tuve dificultades para cambiar el estilo de los checkmarks, al parecer si queres cambiar el estilo tenes que sacarle todos los estilos por defecto y usar background-image, utilize IA para esto.
